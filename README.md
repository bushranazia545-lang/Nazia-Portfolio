# Nazia Portfolio

A personal portfolio website showcasing Upwork contracts, services, and case studies.  
Built with **Vite + React + Tailwind CSS**.

## 🚀 Features
- Responsive design
- Case studies of completed contracts
- Service offerings
- Contact form

## 🛠️ Tech Stack
- Vite
- React
- Tailwind CSS

## 📦 Installation
```bash
git clone https://github.com/bushranazia545-lang/Nazia-Portfolio.git
cd Nazia-Portfolio
npm install
npm run dev
